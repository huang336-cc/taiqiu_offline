# 发布记录

## v1.0.4（当前可用版本）

发布时间：2026 年 8 月 3 日

### 主要改动

- **应用改名**：桌面图标、启动器、主菜单顶部标题均改为「**奥特曼的台球**」。
- **训练模式新手引导**：「自己练习」开局前先弹出操作介绍，设置中可关闭。
- **音效放大与中袋力度音效**：全局音量提升 1.8×；新增 `pot_light` / `pot_mid` / `pot_heavy` 三档中袋音效，按入袋瞬间球速自动选择。
- **系统返回键二次确认**：游戏内按 back 弹「继续游戏 / 返回主菜单」菜单。
- **电脑对战每回合时间限制**：设置新增无限制 / 10s / 20s / 30s 四档；超时判负。
- **README 增加游戏预览图**（docs/screenshots/）。
