## 三、玩法

| 玩法 | 规则简述 | 可选对手 |
|---|---|---|
| 九球 | 按号码顺序击球，先进 9 号者胜 | 练习 / 电脑·稳健 / 电脑·激进 |
| 八球 | 清完己方半区，再打黑 8 获胜 | 练习 / 电脑·稳健 / 电脑·激进 |
| 斯诺克 | 红球彩球交替，比拼总分 | 练习 / 电脑·稳健 / 电脑·激进 |
| 三库开伦 | 无袋台，碰三库后撞两球得分 | 仅练习（无袋口，电脑策略不适用） |

**电脑对手风格**
- **稳健**：优先选择成功率高的球，适合新手对局
- **激进**：偏爱难度更高的进攻路线，挑战性更强

## 四、操作

### 基本操作
| 动作 | 方式 |
|---|---|
| 旋转视角 | 球桌上单指左右拖动 |
| 调整俯仰 | 单指上下拖动 |
| 缩放画面 | 双指捏合 |
| 击球 | 点击右下角「击球」按钮 |
| 力度 | 拖动力度滑条，百分比实时显示 |

### 加塞与杆法
- **击球点**：在白色母球图示上点选。偏上为高杆（跟进），偏下为低杆（缩杆），左右为左右塞
- **抬杆角度**：点击母球图示旁的「+」，用于跳球或加强弧线
- **复位**：双击母球图示，击球点回到正中心

### 摆球（自由球）
对手犯规后可获得自由球，拖动母球到任意合法位置，再点「击球」进入瞄准。

### 视角切换
点击右下角 🎥 循环切换：跟随视角 → 俯视全局 → 母球视角。俯视便于规划走位。

### 外接键盘
| 按键 | 功能 |
|---|---|
| ← → | 左右微调瞄准 |
| ↑ ↓ | 调整力度 |
| 空格 | 击球 |
| Shift + 方向键 | 精细微调 |
| C | 切换视角 |

## 五、设置项

进入主菜单 →「游戏设置」。所有设置立即生效并自动保存。

### 画面
六档画质，首次启动会根据设备内存、CPU 核心数、GPU 型号自动推荐：

| 档位 | 说明 |
|---|---|
| 极速 | 极低分辨率渲染，像素风，帧率最高最省电 |
| 流畅 | 降低分辨率与球体精度，适合入门与老旧机型 |
| 标准 | 常规画质，多数中端手机可稳定运行 |
| 高清 | 较高分辨率与球体精度，兼顾清晰与流畅（默认） |
| 超清 | 开启抗锯齿，边缘更平滑，建议中高端机型 |
| 极致 | 最高渲染精度，建议旗舰机型，耗电较高 |

也可随时点「重新检测」让程序重新推荐。

### 声音
- 音效开关
- 音量（0～100%）

### 操作
- 瞄准辅助线（关闭后更具挑战性）
- 震动反馈

### 其他
- 恢复默认设置

## 六、性能建议

- 卡顿时优先下调画质档位，「流畅」档在千元机上也能跑满帧
- 关闭震动反馈可略微省电
- 游戏为横屏设计，竖屏握持时会自动旋转

## 七、改造说明

相对上游原版所做的主要改动：

**中文化**
- 菜单、玩法说明、设置面板、操作介绍全部重写为中文
- 游戏内击球按钮、摆球提示、得分板、犯规原因、胜负结算全部汉化
- 斯诺克彩球名称（黄球/绿球/咖啡球/蓝球/粉球/黑球）汉化

**离线化**
- 移除 WebSocket 多人大厅与消息中继
- 移除分数上传、遥测统计、崩溃上报
- 移除 Google Fonts 外链，改用系统字体
- 移除分享外链、局面图导出、在线分析面板
- APK 不声明网络权限，从系统层面杜绝联网

**移动端适配**
- 新增 6 档 LOD 画质系统，控制渲染分辨率、抗锯齿、球体几何精度
- 首次启动自动检测设备性能推荐档位
- 界面适配刘海屏安全区域，横屏布局优化
- 新增震动反馈（进球、碰撞）

**新增功能**
- 中文主菜单（玩法选择、对手选择）
- 内置操作介绍页，首次启动自动展示
- 内置游戏设置面板，设置在菜单与游戏内实时同步
